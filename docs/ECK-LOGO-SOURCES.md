# ECK launcher assets

Checked against official sources on 2026-11-21. These marks identify third-party installed apps; all trademarks remain with their owners. They do not imply sponsorship. Source artwork is kept in its original proportions; empty canvas margins and raster resolution are adjusted only for legibility and memory use on TV.

| App | Asset and official reference |
| --- | --- |
| YouTube | Existing bundled full-color/white wordmark, visually checked against [YouTube Brand Resources](https://brand.youtube/). |
| Netflix | Red full wordmark from [Netflix Company Assets](https://about.netflix.com/en/company-assets), `Netflix-Brand-Logo.png`, replacing the small N on the ECK shelf. |
| Disney+ | Refreshed logo from [Disney+ Press](https://press.disneyplus.com/about/disney-plus-logo-2024), `disney_logo_march_2024_050fef2e.png`. |
| Prime Video | White wordmark served by [Prime Video](https://www.primevideo.com/), `pv_logo_white._CB548637580_.png`. |
| HBO Max | Current stacked iridescent white logo from [HBO Max Brand Guidelines](https://brand.hbomax.com/logos), `HBO Max_Iridescent White.jpg`. The older Max-only mark is not used on the ECK shelf. |
| Internet | Original generic globe SVG, labeled İnternet. This is not the Samsung mobile Browser logo and does not claim a particular TV browser version. Launches the installed TV browser. |
| Apple TV | Current iridescent hero logo from the ZIP linked by [Apple TV Press](https://www.apple.com/tv-pr/about/), `Apple_TV_Hero_Logo.jpg`. |
| Spotify | Green full wordmark from the [Spotify media kit](https://newsroom.spotify.com/media-kit/logo-and-brand-assets/), `Spotify_Full_Logo_RGB_Green.png`. |

The fixed shelf order is YouTube, Netflix, Disney+, Prime Video, HBO Max, İnternet, Apple TV, Spotify. Only actual installed ids may be launched. Missing services remain visible with a “Yüklü değil” badge and an explanatory action, never a guessed id or a silent fallback to a different app. YouTube Kids must not replace YouTube; Amazon Music must not replace Prime Video; unrelated names containing “max” must not replace HBO Max.

Raster logo assets are bundled locally so the shelf does not depend on third-party network availability at startup. No account data or device-specific icons are included in the public repository.
